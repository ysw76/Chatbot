# 🏥 육아맘 의료진 찾기 — Streamlit 챗봇

충남 천안시의 주말 진료 가능한 소아청소년과, 가정의학과를 찾아주는 AI 기반 의료진 검색 챗봇입니다.

---

## ✨ 주요 기능

### 1. 🔍 병원 검색
- **진료과별 검색**: 소아청소년과, 가정의학과
- **증상별 추천**: 감기, 발열, 기침, 구토, 피부질환, 예방접종
- **지역별 검색**: 서북구, 동남구
- **주말 진료 필터**: 토요일/일요일 진료 가능 병원 우선 표시

### 2. 👶 아이 정보 관리
- 엄마 이름, 아이 나이, 연락처 저장
- 아이 증상/필요 진료과 선택

### 3. 📋 검색 기록 관리
- 검색 기록 자동 저장 (JSON 파일)
- 통계 정보 (총 메시지, 사용자/의료진 메시지 분류)
- 대화 초기화/삭제 기능

### 4. 🤖 Claude AI 상담 (선택)
- **자연스러운 의료 상담**: AI가 증상을 듣고 공감
- **병원 추천**: 증상과 시간에 맞는 병원 추천
- **건강 팁**: 예방 및 건강 관리 조언

---

## 🚀 설치 & 실행

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 앱 실행 (기본 모드)
```bash
streamlit run main.py
```

### 3. Claude AI 상담 활성화 (선택사항)
- **API 키 취득**: [Anthropic Console](https://console.anthropic.com/)에서 API 키 발급
- **앱에서 설정**:
  1. 왼쪽 사이드바 → "AI 상담 설정" 클릭
  2. Anthropic API 키 입력
  3. "✅ Claude API 연결 완료!" 표시 확인

---

## 📱 사용 방법

### 1단계: 아이 정보 입력
1. 왼쪽 사이드바의 "👶 아이 정보 & 증상" 폼 작성
   - 엄마 이름
   - 아이 나이 (예: 3세, 6개월)
   - 연락처
   - 아이 증상/필요 진료과 선택
2. "정보 저장" 버튼 클릭

### 2단계: 의료진 검색
1. **검색 필터 설정** (선택):
   - 지역 선택 (서북구/동남구/전체)
   - 진료과 선택 (소아청소년과/가정의학과/전체)
   - 주말 진료만 체크

2. **검색 방법 선택**:
   - **빠른 검색**: 미리 설정된 버튼 클릭
     - "🏥 주말 진료"
     - "👶 소아청소년과"
     - "🤒 발열"
     - "💊 예방접종"
   - **자유 검색**: 검색 창에 원하는 내용 입력
     - "아이가 감기에 걸렸어요"
     - "토요일 진료 병원"
     - "예방접종 하고 싶은데..."

3. "🔍 검색" 버튼 클릭

### 3단계: 결과 확인
- 병원명, 주소, 전화번호, 진료시간 확인
- 우측 사이드바에서 검색 기록 저장

## 🐛 문제 해결

### 1. "검색 결과가 없습니다" 표시
- 조건을 다시 확인해보세요
- 지역이나 진료과 필터를 해제해보세요

### 2. Claude API 연결 오류
- API 키가 유효한지 확인하세요
- 남은 크레딧이 있는지 Anthropic Console에서 확인하세요
- 키를 다시 입력해보세요

### 3. 앱이 느리거나 응답이 없음
- 브라우저 캐시 삭제
- `streamlit run main.py` 다시 실행
- 병원 데이터 파일 확인
